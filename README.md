## Shared DNA across all three

- Style: modern seinen anime (Chainsaw Man / Jujutsu Kaisen reference)
- Palette: `#0b0b0b` ink / `#f5efe2` cream / `#e25038` Cocoon coral / `#9e2010` deep rust
- Wardrobe: black fine-knit mock-neck turtleneck, single fine gold chain
- Accessories: small septum ring, tiny gold stud earrings
- Expression: direct composed gaze, closed-mouth, faintest smirk
